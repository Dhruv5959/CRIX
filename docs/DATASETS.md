# CRIX datasets — provenance, licence, size

This file is the authoritative inventory of **every dataset CRIX loads or ships**.
The machine-readable copies live in [`datasets/`](../datasets/) (a readable export,
regenerated by `backend/scripts/export_datasets.py`); the runtime **source of
truth** for curated data is the YAML under `backend/app/data/`.

Nothing in this repository is a third-party dataset. There is **no external
dataset dependency**, so there are no third-party licence obligations to satisfy:
every file below is either generated by this project or hand-authored by this
project from public vendor documentation.

Rule for this project: a value is either **measured**, **hand-verified static**
(cited), **synthetic** (generated, clearly labelled), or **unavailable**.
Nothing is estimated and nothing is presented as measured when it is not.

---

## 1. Machine-learning corpus — SYNTHETIC

Generated deterministically by `backend/app/ml/dataset.py` with `seed=1234`.
Train and test use **disjoint template families**, so the reported metrics measure
generalisation to unseen templates *within a synthetic distribution*. They are
**not** claims about real-world phishing detection.

| File | Rows | Size (bytes) | Purpose |
|------|-----:|-------------:|---------|
| `phishing_corpus_train.jsonl` | 223 | 48,833 | Fits the TF-IDF + logistic-regression phishing classifier and the stylometric AI-text detector. |
| `phishing_corpus_train.csv` | 223 | 36,445 | Same rows, CSV view. |
| `phishing_corpus_test.jsonl` | 153 | 31,881 | Disjoint-template held-out set → precision / recall / F1 / confusion matrix. |
| `phishing_corpus_test.csv` | 153 | 23,345 | Same rows, CSV view. |
| `phishing_corpus_heldout.jsonl` | 4 | 511 | Hand-authored examples used by the end-to-end smoke test. |

Fields: `text`, `phishing` (0/1), `ai_generated` (0/1), `family`.

- **Source:** generated in-repo (`backend/app/ml/dataset.py`, `seed=1234`).
- **Licence:** project-authored (same as this repository). No third-party text.
- **Privacy:** fully synthetic strings; no real person, address or message.

copied prose.

## 3. Not datasets — MEASURED AT RUNTIME

These are **computed**, never stored as datasets, and must never be hard-coded:

- Risk scores, bands and intervals (deterministic risk engine).
- Shapley attributions (exact cooperative-game values).
- Remediation plans (greedy baseline vs exact branch-and-bound).
- Correlation results derived from the rules above.
- ML metrics — persisted to the `evaluation_records` **table** by
  `backend/scripts/run_evaluation.py`, reported with the exact split, seed and
  sample counts. Untested metrics are labelled "not yet measured".

## 4. Reproducing

```powershell
# Regenerate the readable exports (datasets/*.json, *.csv, *.jsonl, DATASETS.md)
.\.venv\Scripts\python.exe backend\scripts\export_datasets.py

# Recompute the measured metrics and persist them to evaluation_records
cd backend
..\.venv\Scripts\python.exe scripts\run_evaluation.py
```

The exports are byte-reproducible from the YAML sources because the ML corpus is
generated with a fixed seed and the curated files are static.
